## 2. 组件库

### 2.1 按钮

| 样式             | 描述                                         |
|------------------|----------------------------------------------|
| `.btn-primary`   | 绿色实心 `bg:accent, color:surface`          |
| `.btn-secondary` | 透明底 + 边框 `border:border, color:fg`      |
| `.btn-ghost`     | 无边框透明 `color:fg`，hover 变 accent       |
| `.btn-arrow`     | 后缀 → 箭头，hover 右移 2px                  |

交互：`:active` 下移 1px；`:hover` 背景加深

### 2.2 卡片

| 样式          | 描述                                    |
|---------------|-----------------------------------------|
| `.card`       | 白底 + 边框 + 圆角 + 28px 内边距       |
| `.card-flat`  | 无背景无边框，纯内容布局               |
| `.card.accent`| 绿底白字，高亮卡片                     |
| `.card.flat`  | 顶部分割线样式                         |

### 2.3 标签

| 样式     | 描述                                          |
|----------|-----------------------------------------------|
| `.pill`  | 强调色浅底 + accent 文字 + 圆角999 + mono字体 |
| `.tag`   | 透明底 + border + muted 文字 + 圆角999        |

### 2.4 搜索框

- 白底 + border + 圆角 14px (iOS) / 28px (Android)
- 左侧搜索图标 + placeholder 灰字
- `.search-bar` 组件

### 2.5 其他

- **Eyebrow**: mono 字体、12px、大写、accent 色、0.08em 字距 → 区块标题上方标注
- **Meta**: mono 字体、辅助文字色 → 时间戳、距离等
- **Quote**: display 字体、大号、带引号装饰 → 用户推荐语
- **Step Flow**: 三列编号步骤，序号用 display 字体、accent 色、低透明度

## 4. 页面详细规格

### 4.1 营销落地页（Responsive Web）

**布局**：单栏居中，最大宽度 1120px，响应式断点 920px

**区块顺序**：
1. **TopNav** — 粘性顶部、毛玻璃背景、Logo + 导航(功能/使用方式/社区) + 下载按钮
2. **Hero** — 居中大标题 "发现你的下一个钓点" + 副文案 + 双按钮(下载App/了解更多)
3. **核心功能** — 三列 Feature 卡片（精准坑点标注 / 路线下载导航 / 社区教学分享）
4. **产品预览** — 左文右图 split 布局 + 手机 Mockup 展示 App 首屏
5. **使用方式** — 三步流程（发现坑点 → 下载路线 → 分享经验）
6. **社区评价** — 用户推荐语引用
7. **CTA** — 居中、下载 iOS/Android 双按钮
8. **Footer** — 版权 + 联系邮箱(hello@yulu.app)

**手机 Mockup 组件**：
- 尺寸 280×580px (桌面) / 220×450px (移动)
- Dynamic Island、圆角 40px、深色渐变边框
- 内嵌迷你 App 界面（状态栏、搜索框、钓点卡片、路线列表、Tab Bar）

### 4.2 iOS 首页

**设备规格**：iPhone 15 Pro · 390×844px · Dynamic Island · 侧按键

**内容结构**（自上而下）：
1. **Header** — 日期 + "你好，钓友" 标题 + 消息/设置按钮
2. **天气条** — 图标 + 温度/风力/气压 + "宜出钓" 药丸
3. **搜索框** — "搜索钓点、路线、教程…"
4. **商城 Banner** — 渐变背景卡片 + 标题/描述/CTA 按钮
5. **附近热门钓点** — 横向滚动卡片组
   - 每卡片：图片区(200×100) + 名称 + 距离·鱼种·钓法 + 标签(深水/岩石底等)
6. **最新路线** — 列表项
   - 每项：图标 + 路线名 + 坑点数·距离·上传者 + 下载按钮
7. **钓友动态** — Feed 流
   - 每条：头像 + 用户名 + 内容文案 + 时间·地点
8. **Tab Bar** — 5 Tab（首页高亮）

**交互**：内容区可滚动，Tab Bar 固定底部，毛玻璃背景

### 4.3 Android 首页

**设备规格**：Pixel 风格 · 412×900px · 挖孔摄像头

**与 iOS 差异**：
- 挖孔摄像头（非 Dynamic Island）
- 搜索框圆角 28px（Material 风格）
- 按钮/卡片圆角更大（Material 3）
- 底部导航使用 Material 3 样式（pill 形选中指示器）
- 无侧按键栏杆

### 4.4 坑点路线（iOS）

**内容结构**：
1. **Header** — "坑点路线" 标题 + 搜索/上传按钮
2. **地图区域**（260px 高）
   - 网格背景模拟地图
   - 坑点 Pin（带名称标签，active/user 状态区分）
   - 路线连线
   - 缩放/定位控件
3. **筛选器** — 横向滚动药丸（全部/路线/坑点/路亚/台钓/湖钓/溪流）
4. **路线详情卡片**
   - 标题 + 上传者 + 日期 + "精选路线" 药丸
   - 统计：坑点数 / 总距离 / 下载量
   - 标签组：鱼种·钓法·水域类型
   - 描述文案
   - 下载按钮："下载路线 · 离线可用"
5. **路线包含的坑点** — 编号列表
   - 每项：序号 + 名称 + 水深·底质·鱼种 + 距离

### 4.5 实时导航（iOS）

**全屏地图**：
- 网格底图 + 水域形状 + 路线折线（实线已走/虚线未走）
- 坑点 Pin 三态：`visited`（实心绿）/ `next`（大号高亮）/ 默认
- 用户位置点 + 朝向箭头 + 光晕

**叠加层**：
1. **转向提示条** — 图标 + 距离(大号数字) + 方向文字
2. **ETA 信息栏** — 到达时间 / 剩余时间 / 剩余距离 / 坑点进度(3/12)
3. **地图控件** — 放大/缩小/定位按钮

**底部抽屉**：
- 路线名称 + 元信息（坑点数·距离·上传者）
- 进度条（已走/剩余）
- 路点列表（已完成/当前/待到达），每项含编号、名称、水深底质鱼种、距离
- 操作按钮：`结束导航`（红色边框）/ `标记坑点`（绿色实心）

### 4.6 钓技教学（iOS）

**内容结构**：
1. **Header** — "学习" 标题 + 搜索按钮
2. **搜索框** — "搜索教程、技巧…"
3. **分类药丸** — 全部/路亚/台钓/传统钓/坑点技巧（选中态为 accent 实心）
4. **精选视频** — 大卡片
   - 封面图 + 播放按钮(48px) + 时长标签
   - 标题 + 作者·播放量·时间 + 标签
5. **热门教程** — 列表
   - 每项：缩略图(80×56) + 播放按钮 + 时长 + 标题 + 作者 + 播放量
6. **精选文章** — 卡片
   - 分类标注(uppercase mono) + 标题 + 摘要 + 作者·阅读时间·阅读量

### 4.7 个人中心（iOS）

**内容结构**：
1. **Profile Header** — 头像(60px) + 昵称 + 简介
2. **统计行** — 四列：分享坑点 / 分享路线 / 获赞 / 粉丝
3. **分享操作** — 双按钮：分享坑点(accent 实心) / 分享路线(描边)
4. **我的路线** — 列表
   - 每项：图标 + 路线名 + 坑点数·距离·下载量 + 时间
5. **我的技巧分享** — 列表
   - 每项：图标 + 标题 + 收藏数·评论数 + 时间

### 4.8 iOS 桌面小组件

**Medium Widget**（360×170）：

## 6. 核心用户流程

### 6.1 发现并到达钓点

1. 打开 App → 首页看到附近热门钓点 + 天气建议
2. 切换到「坑点」Tab → 地图浏览附近坑点
3. 筛选（鱼种/钓法/距离）→ 选择目标路线
4. 查看路线详情 → 下载离线路线
5. 切换到「导航」Tab → 沿路线导航
6. 到达坑点 → 可标记新坑点

### 6.2 分享经验

1. 「我的」Tab → 点击「分享坑点」或「分享路线」
2. 标注坐标、水深、鱼种、最佳时段
3. 发布到社区 → 其他钓友可查看、下载、评论

### 6.3 学习钓技

1. 「学习」Tab → 浏览分类教程
2. 观看视频教程 / 阅读文章
3. 收藏、评论、分享

## 7. 技术备注

### 7.1 响应式断点

- `920px` — 多列布局切换单列（grid-2, grid-3, grid-4, hero-split）
- 移动端优先：所有 grid 在 920px 以下退化为单列

### 7.2 CSS 特性使用

- `color-mix(in oklch, ...)` — 颜色混合（accent-soft, fg-soft）
- `backdrop-filter: blur(12-20px)` — 毛玻璃效果（TopNav, Tab Bar）
- `clamp()` — 流式字号和间距
- `text-wrap: balance/pretty` — 文本排版优化
- CSS Custom Properties — 完整的 Design Token 体系

### 7.3 横向滚动组件

- `.h-scroll` — 容器 `overflow-x: auto`, `scroll-snap-type: x mandatory`
- 子元素 `scroll-snap-align: start`, `flex-shrink: 0`
- 隐藏滚动条 `::-webkit-scrollbar { display: none }`

### 7.4 iOS 设备模拟细节

- Dynamic Island：124×36px 黑色圆角矩形
- 侧按键栏杆：4px 宽渐变条
- Home Indicator：134×5px 圆角条
- 状态栏：信号/WiFi/电池 SVG 图标组

### 7.5 Android Material 3 差异

- 挖孔摄像头（14px 圆形）
- 底部导航 pill 形选中指示器（48×28px 圆角背景）
- 搜索框圆角 28px
- 更大的触控区域（按钮 40px）
